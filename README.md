# 在庫管理（仕入れ・出品・販売の記録）

iPhoneのブラウザで使える、1ファイル完結の在庫管理アプリです。データは端末（ブラウザ）の中だけに保存され、サーバーには送信されません。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体（これ1つで動作します。背景画像も内部に埋め込み済み） |
| `apple-touch-icon.png` | iPhoneのホーム画面に追加したときのアイコン（180×180） |
| `icon-192.png` / `icon-512.png` | Android・アプリ情報用のアイコン |
| `manifest.webmanifest` | ホーム画面アプリとして起動するための設定 |
| `.nojekyll` | GitHub Pagesで不要な処理を止めるための空ファイル |

## GitHub Pagesで公開する手順

1. GitHubで新しいリポジトリを作成（Public／Privateどちらでも可）
2. このフォルダの中身を**すべて**アップロード（`index.html` が一番上に来るように）
3. リポジトリの **Settings → Pages**
4. **Source** を `Deploy from a branch`、**Branch** を `main` / `(root)` にして **Save**
5. 1〜2分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

> PrivateリポジトリのGitHub Pagesは有料プランが必要です。無料で使う場合はPublicにしてください。

## iPhoneでアプリのように使う

1. Safariで公開URLを開く
2. 「スクリプトを実行」を押す（※プレビュー画面では入力画面が表示されないことがあります。Safariで開いてください）
3. 共有ボタン →「**ホーム画面に追加**」
4. ホーム画面のアイコンから起動（全画面でアプリのように動きます）

## 使い方（概要）

- **入力**：仕入れ回を入れると管理番号（例 7-10）が自動で付きます。「コピー」を押してメルカリ等の出品画面に貼り付けできます。
- **一覧**：在庫・出品中・売却済を切り替えて確認。30／60／90日の滞留切替つき。
- **集計**：月別・仕入れ回別・仕入先別・販路別、在庫の古い順、赤字の一覧。
- **使い方**：操作の手順。
- **データ**：CSV書き出し／追加読み込み／置きかえ、JSONバックアップ、背景の切替（イラスト／うすいピンク／無地）。

## 大切な注意

- データは**その端末のブラウザにだけ**保存されます。機種変更・ブラウザ変更の前に、**データ → バックアップ（JSON）** を取ってください。
- 同じURLでも、別の端末や別のブラウザでは別のデータになります。
- 「CSVで書き出す」でExcelに取り込めます（文字コードUTF-8）。Excelで開く場合は、文字化けするときUTF-8として読み込んでください。
